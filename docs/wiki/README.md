# Wiki Pages

Source files for the [GitHub Wiki](https://github.com/oxsource/bazel_git_lfs/wiki).

## Publishing

```bash
git clone https://github.com/oxsource/bazel_git_lfs.wiki.git
cp docs/wiki/*.md path/to/bazel_git_lfs.wiki/
cd path/to/bazel_git_lfs.wiki
git add -A && git commit -m "Update wiki" && git push
```

> The wiki repository is created automatically when you first visit `https://github.com/oxsource/bazel_git_lfs/wiki`.
