# Configuration

`bazel-git-lfs` keeps configuration minimal and project-local. The main
behavioral configuration lives in a lightweight INI-style file,
`.bazel_git_lfs/.bazelconfig`. Everything else under `.bazel_git_lfs/` is
either derived data or the inner object repository.

## Configuration Files

| File | Purpose | Versioned |
|------|---------|-----------|
| `.bazel_git_lfs/.bazelconfig` | Behavior overrides (server port, inspect filters) | ✅ (tracked via `!.bazel_git_lfs/.bazelconfig`) |
| `.bazel_git_lfs/dependencies.json` | Inspect snapshot (regenerated by `inspect`) | ❌ |
| `.bazel_git_lfs/manifest.json` | Object manifest (generated by `inspect`) | ❌ |
| `.bazel_git_lfs/checkout-state.json` | Current checkout state | ❌ |
| `.bazel_git_lfs/objects/` | Inner Git LFS repo of mirrored object files | ❌ |

There is **no global configuration file** and **no `config.json`** — the legacy
`config.json` (remote profiles/aliases) was removed. Mirror remotes are managed
directly through `bazel-git-lfs remote` (a passthrough to
`git -C .bazel_git_lfs/objects remote`).

## The `.bazelconfig` File

`.bazel_git_lfs/.bazelconfig` is a project-local INI-style file that overrides
hard-coded behavior. Supported keys:

| Key | Default | Description |
|-----|---------|-------------|
| `server.port` | `8022` | Port used by the local object HTTP server (`checkout @`). |
| `inspect.exclude` | *(none)* | Dependency names (exact match) to exclude from archiving during `inspect`. |
| `inspect.append` | *(none)* | Manually-added dependencies that the scan missed. |

During `init`, the external repository's `.gitignore` is updated to track
`.bazelconfig` in version control:

```gitignore
.bazel_git_lfs/*
!.bazel_git_lfs/.bazelconfig
```

### Example

```ini
# .bazel_git_lfs/.bazelconfig

[server]
port = 9022

[inspect]
exclude = some_unwanted_dep
exclude += another_dep

append = manual_dep|https://example.org/m.tar.gz|a1b2c3d4...e5f6
```

### More

For the full syntax, supported keys, and behavior, see
[[BazelConfig]].

## Environment Variables

There are no configuration environment variables. (The legacy
`BAZEL_GIT_LFS_HOME` global-config override was removed along with `config.json`.)

## Pre-commit Hook

When you run `bazel-git-lfs init` in a git repository, the tool installs a
pre-commit hook at `.git/hooks/pre-commit`. This hook automatically runs
`bazel-git-lfs checkout default` before each commit if a non-default checkout
state is detected, preventing non-default URLs from being committed.
